# Ryladmin

Ryla's Administrator continuity repository for the Ensemble / Kymaean system.

Fresh Administrator chats read `AGENTS.md` first, then `CURRENT_STATE.md`, and re-resolve all live Ensemble authority before acting. If the machine/runtime is missing, use `docs/ADMINISTRATOR_DISASTER_RECOVERY.md` and the executable `recovery/` kit before resuming Administrator execution.

Ryladmin records Administrator continuity only. It never overrides `Rylascoo/Ensemble-Project`, `Rylascoo/Ensemble-Website`, their owning authority files, or connected project assets.
